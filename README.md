# Drive Playlist Service Worker Build

Upload these files to the root of your GitHub Pages repository:

- index.html
- style.css
- script.js
- sw.js

Important first run:
1. Open the site.
2. If it says first-time setup complete, refresh the page once.
3. Connect to Google Drive.
4. Load the folder.
5. Tap a video/play if Android blocks autoplay.

This version uses a service worker so the HTML video player can stream private Google Drive files with the OAuth token added in the background.
